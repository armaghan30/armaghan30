## 🧑‍💻 About Me

Final-year **BS Computer Science** student at **FAST NUCES Lahore**, specializing in cybersecurity with a Purple Team mindset. I build offensive tools, break into systems (legally), and then figure out how to defend them.

- 🔴 **Offensive**: Penetration Testing, Web Exploitation, Active Directory Attacks, Privilege Escalation
- 🔵 **Defensive**: SIEM, Incident Response, Network Defense, Threat Detection
- 🟣 **Purple**: Building an [AI-Powered Cyber Drill System](https://github.com/armaghan30/ai-powered-cyber-drill-system) — my FYP using Reinforcement Learning (DQN & PPO) to simulate Red vs. Blue adversarial scenarios
- 🏢 Former Intern @ **Systems Limited** — Digital Infrastructure & Security Services
- 🎯 Sharpening skills daily on **TryHackMe** & **Hack The Box**
